# Uperfect TikTok Shop export

Requested public product URLs are recorded in `export-manifest.json`.

No product metadata or product media was exported. On 2026-08-10, each URL
returned TikTok Shop's **Security Check** CAPTCHA to unauthenticated public
access. CAPTCHA images were deliberately excluded because they are not product
assets.

To complete the export, provide product details/media from an authorized
session, or open each link in a browser where you are already signed in and
clear the verification manually. I can then organize the supplied public
product data in this folder.
